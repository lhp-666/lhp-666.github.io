Bugku CTF 这是一张单纯的图片

题目分类：MISC

解题思路

  1. 访问题目页面，下载图片保存到本地电脑。
  2. 找到图片所在的文件夹。
  3. 双击直接打开，只能看到小兔子表情包，看不到flag。
  4. 尝试使用格式转换软件修改，无法获取隐藏信息。
  5. 在文件夹上方勾选“文件扩展名”，显示出后缀名，将 .jpg 修改为 .html。
  6. 用火狐浏览器打开修改后缀后的文件，页面会出现大量乱码。
  7. 按下快捷键 Ctrl + F，在搜索框输入 key，直接定位到flag。
  8. 复制flag，回到Bugku题目页面粘贴提交，解题成功。

总结后的操作步骤

  1. 下载题目中的图片文件。
  2. 打开图片所在文件夹，开启显示文件扩展名，把后缀 .jpg 修改成 .html。
  3. 使用浏览器打开文件，按下 Ctrl + F，搜索关键词 key。
  4. 复制搜索出来的flag，回到题目页面粘贴提交，完成解题。

总结收获

  1. 这个文件里面同时存放图片数据和HTML编码文本。后缀只是告诉电脑用什么软件打开，不会改变文件本身内容。jpg看图软件只会解析图像，忽略末尾隐藏文字；浏览器读取全部内容，自动解码文本。
  2. Ctrl + F 页面搜索功能，可以在一大堆文字、乱码里面，快速定位关键字，不用手动翻阅全部内容。
  3. 不要使用格式转换软件，格式转换只会处理图像画面，无法读取追加在文件尾部隐藏的数据。
